# 07 — Control UI / Watch UX triage

**Lens:** Solo operator. Clarity and process honesty beat polish and gamification.  
**Scope:** Control UI, Watch, Docs, Demos — practical only. No training-algorithm ideas. No code.

**Bias (explicit):** Prefer Start/Stop honesty, continue train, model load/delete, map gen, coach — over seasons, XP, confetti, vibes dials, or “you’re crushing it” lies.

**Already on radar (confirmed backlog, not novelty):** map generator UI; load/delete models; continue training; checkpoint timeline; coach panel; plain-language Start/Stop; TB auto-open; Watch follow twins + multi-color cars; compare / ghost vs FTG.

---

## KEEP

Ship or deepen these — they reduce wrong-button risk and make overnight runs legible.

### Control UI

- Plain-language labels (“how many cars practice,” “average score,” “session name”)
- “What’s happening now” banner: Idle / Warming / Learning / Saving / Stopping / Crashed + reason
- Clear UI-owned vs external-train ownership; Stop consequences in plain English
- “What will Start do?” preview card (map, steps, workers, paths) before commit
- Session resume: “Continue last unfinished run?” with reuse vs restart spelled out
- Model timeline: Best / Latest / Checkpoints + “recommended for racing”
- Load / delete models (confirmed radar — treat as must-have, not stretch)
- Map picker with thumbnails + easy/twisty/long tags (not filename lottery)
- Map generator UI surface (confirmed radar) — generate / cache / pick without leaving the panel
- Health panel: CPU/GPU/RAM traffic lights + “too many workers” coach
- Coach panel / grade from reward slope, crash rate, whether Watch was opened (confirmed radar)
- First-run checklist: venv, maps, GPU; empty states with next action
- Post-run summary + next steps; copyable log path / Open folder
- Safe-defaults badge; TensorBoard one-click / auto-open handoff
- Preset chips: Quick try / Overnight / Debug (1 car); Advanced unlock for workers/batch/net
- Progress story + ETA in clock time; outcome-framed timesteps copy
- Lag-behind honesty: label Watch delay so it feels intentional (UI copy, not Watch magic)

### Watch

- Twin rainbow / multi-color cars with named legend (“Worker A… same brain demos”)
- Follow twins lag-behind; pause, reset, freeze policy update, reload newest brain now
- Overlay projected adjusted_time + collisions, not just `ep_rew`
- Ghost rival: yesterday’s best translucent twin (or FTG) to pass — compare, not carnival
- FTG placeholder as faint underdrawing until PPO weights go opaque
- Crash stamps / reason tags (wall / spin / stall) — shame heatmap only if cheap
- Map mismatch banner (Watch map A vs train map B) when status disagrees

### Docs

- First-launch modal: Control UI trains; Watch watches; TB shows curves — three jobs
- Common-mistake library: Watch before train; expecting camera; Watch ≠ loss curves
- “What good looks like” / “Don’t panic” when reward dips; FTG toast until first zip
- Progressive docs: 30s start → 5min understand → deep dive
- End-of-session recap: where logs / models / runs live
- “What is PPO/FTG?” expandables; contracts version tip for v1→v2 zips
- Kill research-notes novel → 20 lines max for the operator path (minimalist)

### Demos (practical)

- One-click “Watch twins learn”; ghost PPO vs FTG; time-to-beat-FTG wallboard
- Conference booth: big twins + iPad with only Start / Stop / Watch
- Leaderboard TV mode / spare-monitor forever-follow (office hours, not a season ladder)

---

## DEFER

Useful later — after Start/Stop, continue, models, map gen, and coach are honest and boring.

### Control UI

- Glossary drawer; large type / colorblind-safe / keyboard Start/Stop (do after core flows work)
- Garage-night aesthetic / “one big starter button” skin (stretch polish)
- Beginner / Intermediate / Advanced progressive disclosure beyond simple preset chips
- Curriculum unlock UI (“Map1 only after Map0 gate”) — needs real gates first
- Compare / promote-to-race-candidate after held-out clean evals (needs eval protocol)

### Watch

- Wall-contact heat map as a first-class viz (keep crash stamps; heat is optional polish)
- LiDAR as sparse “cathedral light”; beams toggle for FPS (nice; not blocking)
- Split-screen: numbers | twins | momentum arrow
- Photo-finish collage / highlight reel on new PB
- Reward weather lighting / emotion beats (atelier stretch — after metrics are trusted)
- Multi-view camera tiles / Grad-CAM (no camera in contract yet)

### Docs / demos

- “From zero to lap” cold start under 3 minutes (stretch demo — after defaults are sane)
- Human vs agent night; clip farm of near-misses
- Season ladder / daily pit / timestep XP / Elo vs FTG (gamification deferred indefinitely unless it doubles as eval)

---

## CUT

Do not build. Entertainment ≠ podium; lying UI and growth theater waste solo-operator time.

### Control UI / status

- Auto-start on page load
- Haiku run names / vibes-only dial / emoji-only status
- Cheerful lying UI (“you’re crushing it” while spinning)
- Voice narrating every timestep
- Hot-swap reward mid-run via UI “chaos dial” / Discord emoji reactions
- 16 Watch windows “for transparency”
- Minimal mode + plugin bus + second advanced UI (simplify-by-adding)

### Watch / aesthetic spam

- Twins argue in speech bubbles; karaoke overlay; rubber-duck throttle meter
- Project Watch 1:1 on garage floor / origami crane per crash / perfume on new best
- Auto-open stock “fake camera” of training
- Soundtrack from steering; risograph dumps; clay racing-line sculpture
- UI that gets uglier the longer training runs

### Docs / demos / growth

- Tooltips that quote papers instead of next click
- Crash bingo, mutation roulette, champagne confetti on PB
- NFT of best_model hash / pay-to-name checkpoint / donate to raise exploration noise
- TikTok crash compilation growth hack; “guaranteed podium or compute back”
- Maximize Watch chaos as if entertainment = podium

### Simplify traps (as product goals)

- Kill Watch / live_status solely to “simplify” — they are the operator’s eyes; keep lag-behind honesty instead
- Kill dual best/latest/checkpoints *theater* is fine as a docs stance until multi-day runs exist — but **do not cut load/delete/continue**; those stay KEEP

## TOP 15

Ordered for a solo operator who must trust Start/Stop tonight and still have a brain tomorrow.

| # | Item | Why |
| - | ---- | --- |
| 1 | Start/Stop honesty + ownership banner | Wrong Stop / dual UI fighting one `runs/` dir is the highest-cost UX failure |
| 2 | “What will Start do?” preview | Commits map, steps, workers, paths before GPU burns |
| 3 | Continue last unfinished run | Reuse vs restart spelled out — already on radar; unblock overnight |
| 4 | Model timeline + load / delete | Best / Latest / Checkpoints; delete bad zips without shell spelunking |
| 5 | “What’s happening now” + Crash reason | Idle / Learning / Saving / Stopping — status must match PID reality |
| 6 | Map picker + thumbnails | End filename lottery; tags beat `map0` guessing |
| 7 | Map generator UI | Generate / cache / pick in-panel — confirmed radar |
| 8 | Coach panel | Reward slope, crash rate, “did you open Watch?” — actionable, not vibes |
| 9 | Health / workers coach | Traffic lights + “too many workers” before Subproc meltdown |
| 10 | Watch lag-behind copy + reload brain | Label delay; pause / reset / reload newest zip — intentional lag, not broken |
| 11 | Multi-color twins + legend | Same-brain demos readable at a glance |
| 12 | Overlay adjusted_time + collisions | Stop worshipping `ep_rew` in the window operator stares at |
| 13 | Ghost FTG / yesterday’s best | Compare to beat, not decorate |
| 14 | Three-jobs first-launch + common mistakes | UI trains / Watch watches / TB curves — kill camera expectations early |
| 15 | Post-run summary + Open folder / TB handoff | Where logs and zips live; one-click TB — closes the loop |

**Explicitly not in Top 15:** seasons, XP, confetti, reward weather, speech bubbles, booth polish beyond Start/Stop/Watch, aesthetic skins.

---

## Operator north star (one line)

One honest panel that starts, stops, continues, loads, deletes, generates maps, and coaches — plus a Watch that admits it lags and shows whether the car is racing or dying.
